# 论文速读：Efficient-Multi-scale-Network-with-Learnable-Discrete-Wavelet

## 一句话总结
提出基于单输入多输出（SIMO）的多尺度网络 MLWNet，结合可学习离散小波变换模块（LWN），在保证计算效率的同时显著提升真实世界运动模糊的盲去模糊质量。

## 研究问题与动机
- **多尺度算法复杂度高**：现有方法需额外融合模块处理不同尺度RGB图像与深层语义，结构冗余。
- **低分辨率图像对置信度不足**：MIMO架构依赖人工插值生成低分辨率图像对，质量不可靠。
- **细节恢复瓶颈**：自顶向下逐层恢复过程中，低尺度特征空间歧义导致高频细节恢复受限。
- **真实模糊轨迹特性未充分利用**：真实模糊具有方向连续性，而现有频率域方法（如DFT）对突变信号适应能力较弱。

## 核心贡献（创新点）
- **SIMO多尺度基线**：仅用单输入图像，多尺度输出渐进恢复，消除多尺度融合模块与低分辨率图像对生成开销。
- **可学习离散小波变换节点（LWN）**：通过分组卷积实现自适应小波变换，将特征从空间域映射至小波域，提取不同方向与频率分量以增强细节恢复。
- **多尺度损失与自监督小波损失**：设计 $w_k=1/k$ 的多尺度损失避免低尺度干扰；引入完美重构条件约束小波核学习方向，防止退化为普通分组卷积。
- **真实场景优异性能与泛化**：在RealBlur-J、RealBlur-R、RSBlur等真实数据集上达到SOTA，且对合成模糊的泛化鲁棒性优于多数基线。

## 方法详解
**网络架构（SIMO）**：编码器（SEB）→ 融合阶段（WFB）→ 解码器（WHB）。输入原始高分辨率图像，各尺度输出分别接 $3\times3$ 卷积生成恢复图像，训练时计算多尺度损失，推理时仅输出最高尺度结果。

**可学习小波变换（LWN）**：
- 由可学习分析向量 $\vec{a}_0$（低通）与 $\vec{a}_1$（高通）构造2D小波核 $\mathcal{K}_w$，通过分组卷积实现正变换与逆变换。
- 正变换后使用扩张深度卷积进行小波域特征提取，$1\times1$ 卷积通道缩放，逆变换返回空间域。
- 引入完美重构条件约束：
  $$A_0(-z)S_0(z) + A_1(-z)S_1(z) = 0$$
  $$A_0(z)S_0(z) + A_1(z)S_1(z) = 2$$
  转化为卷积等价损失 $\mathcal{L}_{wavelet}$ 以零均值形式优化。

**损失函数**：
- 多尺度损失：$\mathcal{L}_{multi} = \sum_{k=1}^{K} \frac{1}{k} \mathcal{L}_{psnr}(x_k, y_k)$
- 总损失：$\mathcal{L}_{total} = \mathcal{L}_{wavelet} + \mathcal{L}_{multi}$

## 实验与结果
- **数据集**：RealBlur-J/R、RSBlur、GoPro（合成）。
- **评估指标**：PSNR、SSIM、计算量（MACs）、运行时间。
- **RealBlur-J**：MLWNet-B达 **33.84 PSNR / 0.941 SSIM**，较SOTA GRL-B提升 **0.49 dB**，运行时间仅0.05s。
- **RealBlur-R**：MLWNet-B达 **40.69 PSNR / 0.976 SSIM**，较GRL-B提升 **0.91 dB**。
- **RSBlur**：MLWNet-B达 **34.94 PSNR / 0.880 SSIM**，为当前最高；在RealBlur-J上测试亦达 **30.53 PSNR**，泛化最优。
- **GoPro（合成）**：33.83 PSNR / 0.968 SSIM，较FFTformer SSIM差距仅0.001，但运行时间减少60%。

## 相关工作脉络
- **MIMO-UNet**（Cho et al.）：多输入多输出U型架构，需多层级融合模块；本文SIMO仅保留原图输入，结构更精简。
- **FFTformer / DeepRFT**：引入DFT频域先验；本文采用小波变换，更适合处理真实模糊的突变信号与方向连续性。
- **SDWNet**：使用固定小波变换；本文LWN通过自适应学习与完美重构损失，使变换贴合数据分布与特征层空间。
- **PSNR loss / NAFNet**：单尺度简单基线；本文多尺度损失引导逐尺度渐进恢复，同时避免低尺度干扰。
- **BANet**：关注模糊轨迹方向性；本文通过小波域方向分量提取直接建模该特性，无需额外注意力模块。

## 局限性与未来方向
- **合成模糊性能未达SOTA**：GoPro上PSNR略低于FFTformer，因合成模糊轨迹不连续、高频信息混杂，小波变换优势受限。
- **噪声敏感性差异**：在真实模糊噪声水平下鲁棒，但合成数据噪声分布差异导致性能波动。
- **未来方向**：扩展至视频去模糊、动态场景联合建模；探索更通用的频域变换机制以兼顾真实与合成数据。

## 研究启发与可借鉴点
- **SIMO架构替代MIMO**：保留原始分辨率输入、多尺度输出渐进恢复，可大幅简化多尺度网络设计，适用于其他图像恢复任务。
- **可学习小波变换+完美重构约束**：将传统信号处理算子参数化并引入解析约束，既保持理论正确性又适配数据分布，思路可迁移至超分、去噪等任务。
- **多尺度损失加权策略**：以 $1/k$ 递减权重平衡各尺度贡献，避免低分辨率输出干扰最终结果，可作为多尺度恢复任务的通用设计。
- **真实-合成域差异分析**：通过噪声水平分层实验揭示模型泛化瓶颈，为跨域适应提供诊断思路。

## 关键术语表
- **SIMO (Single-Input Multiple-Output)**：单输入多输出架构，一次输入原始图像，网络多尺度输出去模糊结果。
- **LWN (Learnable Wavelet Node)**：可学习小波变换节点，通过分组卷积实现自适应2D离散小波正变换与逆变换。
- **2D-DWT**：二维离散小波变换，将图像分解为低频近似分量与高、水平、垂直、对角高频分量。
- **完美重构条件**：小波正逆变换系数满足的数学约束，保证信号经变换后无失真恢复。
- **$\mathcal{L}_{wavelet}$**：自监督小波损失，将完美重构条件转化为卷积等价误差，约束可学习小波核的学习方向。
- **$\mathcal{L}_{multi}$**：多尺度PSNR损失，对各尺度输出图像与对应GT计算加权像素误差。
- **WFB / WHB**：小波融合块 / 小波头块，分别用于多尺度语义融合与渐进解码恢复。
- **SEB**：简单编码器块，以 $1\times1$ 卷积与 $3\times3$ 深度卷积替代小波节点，用于基线网络。
