# 论文速读：PFStorer: Personalized Face Restoration and Super-Resolution

## 一句话总结
本文提出 PFStorer，一种基于扩散模型的个人化面部恢复方法，通过使用少量高质量参考图像对基础恢复模型进行适配，在保留原始身份特征的同时生成高质量、真实的面部细节。

## 研究问题与动机
- **面部恢复的不适定性**：人类对面部的细微变化极其敏感，眼睛、鼻子、嘴唇等形状或颜色的微小差异都会导致身份感知的显著改变。
- **现有生成式方法缺乏身份保真度**：基于 GAN、codebooks 或扩散模型的恢复方法能生成逼真图像，但往往因缺乏特定身份上下文而导致恢复结果与目标身份不符。
- **参考图像方法在非对齐场景下失效**：现有 Reference-Based 方法依赖参考图像与输入图像的相似性或对齐操作，当两者存在姿态、光照或语义差异时性能显著下降。
- **直接微调个人化模型会破坏已有先验**：使用 DreamBooth 等直接微调整个扩散模型的方法会损害基础恢复模型在高质量细节恢复上的能力。

## 核心贡献（创新点）
1. **适配器和可学习参数联合的个人化策略**：冻结基础恢复模型权重，仅训练 Personalization Block（跨注意力适配器），并通过逐层可学习参数 γ^i 控制个性化注入程度，避免灾难性遗忘。
2. **生成式正则化（Generative Regularizer）**：在训练时以随机噪声替代条件 LQ 图像，强制模型仅依靠参考图像学习身份表征，防止模型过度依赖输入图像中残存的身份信息。
3. **对齐无关的训练管道改进**：使用随机裁剪替代关键点检测对齐，结合更高比例的 HQ 直通输入（p_HQ=0.03），使模型更鲁棒且支持 tiling 超分辨率。
4. **端到端个人化恢复框架**：将基础恢复模型（Base Model）与个人化模块有机结合，在重度退化甚至极端场景下仍能忠实还原身份。

## 方法详解

### 整体架构
模型以 StableSR [35] 为基础，在其每个 UNet 块后添加 Personalization Block（图3）。Personalization Block 包含文本嵌入与参考图像特征之间的 cross-attention 机制。

### 个性化适配器（Personalization Block）
- 参考图像特征 F_{Ref}^i 由冻结的 StableDiffusion 提取，在同批次中通过 Base Model 部分网络获得。
- 对每一层 i，输出公式为：
  $$\hat{F}^i = F^i + \gamma^i \odot \text{Personalization-Block}(F^i, F_{ref}^i)$$
  其中 γ^i 初始化为 0，逐层可学习，控制个性化模块对中间特征的注入强度。

### 扩散损失
$$\mathcal{L}_{Diff} = \mathbb{E}_{z,t,I_{LQ},I_{Ref},\epsilon}\|\epsilon - \epsilon_\theta(z_t, c, I_{LQ}, I_{Ref})\|_2$$

### 生成式正则化损失
$$\mathcal{L}_{Gen} = \mathbb{E}_{z,t,I_{LQ},I_{Ref},\epsilon}\|\epsilon - \epsilon_\theta(z_t, c, \emptyset, I_{Ref})\|_2$$
用空输入 ∅ 替代 I_{LQ}，迫使模型在无辅助输入时仍能仅凭参考图像生成身份。

### 总损失
$$\mathcal{L} = \mathcal{L}_{Diff} + \lambda_{Gen}\mathcal{L}_{Gen} + \lambda_{Pers}\mathcal{L}_{Pers}$$
其中 λ_{Gen}=0.1，\mathcal{L}_{Pers} 正则化 learnable text embedding token 的跨注意力图以强化个性化。

### Base Model 训练改进
- 从 StableSR [35] 预训练权重初始化，在 FFHQ 上微调。
- 使用随机裁剪（而非关键点检测对齐），随机 crop + resize 策略增强姿态鲁棒性。
- 退化模拟：二阶噪声模型 + ISP 模型 + 运动模糊 + 中值模糊。
- HQ 直通概率 p_HQ=0.03，确保恢复过程不丢失 HQ 输入的细节。
- Tiling 超分辨率支持：对 >512×512 图像通过瓦片方式实现高达 20× 超分。

## 实验与结果

### 数据集
- **Celeb-Ref**：随机选取 20 个身份（每身份 ≥10 张图），342 张合成测试图（其中 242 张用于测试，每身份预留 5 张作为参考）。
- **真实世界数据**：从 Celeb-Ref 中选取 20 个身份，通过 LAION-5B-KNN 反向搜索收集真实网页图片。

### 评估指标
PSNR、SSIM、LPIPS、MUSIQ（KonIQ）、LMSE、ID（ArcFace 余弦相似度）。

### 定量结果（重度退化，表1）
| 方法 | ID↑ | LMSE↓ | MUSIQ↑ |
|------|-----|-------|--------|
| CodeFormer | 38.33 | 33.34 | 60.92 |
| DMDNet | 29.51 | 89.26 | 47.17 |
| DR2+SPAR | 30.01 | 40.82 | 47.36 |
| **PFStorer** | **57.18** | **18.37** | **64.04** |

- ID 指标较次优方法高出近 **20 个百分点**。
- LMSE 误差约为 CodeFormer 的 **一半**。
- MUSIQ 达到 64.04，超越 GT（62.37）（得益于扩散模型的主观质量增强）。

### 消融实验（表2）
- Base Model（无个性化）ID 为 33.90，加入 DreamBooth 后 ID 升至 52.72 但 PSNR 降至 21.13（低于 StableSR 的 21.68），LMSE 升至 37.48，证明直接微调破坏先验。
- Base + ViCo 改善有限（ID=53.92，LMSE=20.26），缺少 γ 参数的控制导致个性化特征与恢复特征失衡。
- PFStorer 在各项指标上全面最优。

### 用户研究
- 40 名用户，8000 个回答，对比 CodeFormer、DMDNet 和 PFStorer。
- PFStorer 在感知质量上获得 **61%** 投票（次优 CodeFormer 25%）。
- 在身份保真度上领先 CodeFormer 达 **36.6 个百分点**。

### 生成式正则化分析（图9）
- λ_{Gen} 较大时（如 0.3）在重度退化场景下提升效果更佳（更多幻觉填充细节）。
- λ_{Gen} 较大时在小退化场景下反而损害结果（过度幻觉覆盖有效输入信息）。

## 相关工作脉络
1. **CodeFormer [45]**：基于离散 codebook 的 SOTA 盲恢复方法，无需参考图像；PFStorer 在 ID 保真度上大幅超越 CodeFormer（57.18 vs 38.33）。
2. **DR2 [38] + SPAR**：基于扩散模型的极端退化恢复方法；PFStorer 通过引入参考图像和个人化适配，在身份保持上显著更强。
3. **DMDNet [24]**：参考图像面部恢复的 SOTA，依赖特征对齐；PFStorer 通过神经身份表征摆脱了对齐约束。
4. **DreamBooth [30]**：个人化扩散生成的开创性工作，直接微调全模型；PFStorer 改用适配器策略保留基础恢复先验。
5. **ViCo [14]**：在 cross-attention 层添加图像适配器进行个人化；PFStorer 将其扩展到扩散恢复任务，并通过 γ 参数和生成式正则化进一步改进。
6. **StableSR [35]**：PFStorer 的基础恢复模型，预训练于自然图像超分任务；本文在此基础上引入个人化适配。

## 局限性与未来方向
- **参考图像外观变化的敏感性**：若参考图像与输入图像之间存在显著外观差异（如发型、配饰），输出可能不符合预期（图10）。
- **扩散模型采样速度慢**：受限于 Stable Diffusion 的固有问题，推理速度较慢。
- **随机性导致的偶发伪影**：扩散模型的随机生成过程可能产生不期望的伪影。
- 未来方向包括与 [6]（Emu）等引导式生成方法结合以提升采样质量和速度。

## 研究启发与可借鉴点
1. **适配器冻结策略的可迁移性**：在需要保留预训练先验的个人化任务中，冻结主网络仅训练适配器的策略值得复用于其他视觉恢复/生成任务。
2. **生成式正则化思想的通用价值**：通过屏蔽条件输入强迫模型学习独立表征的技巧，可用于任何容易陷入"捷径学习"的多模态条件生成任务。
3. **对齐无关训练的实用意义**：随机裁剪策略避免了关键点检测失败导致的系统性误差，适用于真实场景中人脸姿态多变、检测不可靠的情况。
4. **γ 参数的逐层控制机制**：不同分辨率层级独立调节个性化注入强度，为多层网络中个性化与通用特征的平衡提供了精细控制手段。
5. **与个人化生成模型的范式差异**：将"个人化"从生成任务迁移至恢复任务，证明恢复模型同样具备可个性化潜力，拓展了个人化技术的应用边界。

## 关键术语表
- **PFStorer**：本文提出的个人化面部恢复模型，基于扩散适配器实现身份保真的高质量恢复。
- **Personalization Block**：插入基础模型各层的跨注意力适配器模块，通过可学习参数 γ 控制个性化特征注入。
- **生成式正则化（Generative Regularizer）**：训练中用空输入替代 LQ 条件，强制模型仅凭参考图像学习身份表征的训练技巧。
- **对齐无关方法（Alignment-Free）**：不使用关键点检测进行人脸对齐，而是依赖随机裁剪增强鲁棒性的训练策略。
- **StableSR**：本文使用的预训练基础恢复模型，在通用图像超分任务上预训练后微调于 FFHQ 面部数据。
- **Celeb-Ref**：用于评估参考图像面部恢复性能的数据集，包含多个身份的人脸图像。
- **FFHQ**：Flickr-Faces-HQ 数据集，包含大量高质量人脸图像，用于训练 Base Model。
- **ID 相似度**：使用 ArcFace 计算生成图像与原始图像之间的余弦相似度，衡量身份保真度的核心指标。
