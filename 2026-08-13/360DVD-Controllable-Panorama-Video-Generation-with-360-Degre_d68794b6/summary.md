# 论文速读：360DVD-Controllable-Panorama-Video-Generation-with-360-Degre

## 一句话总结
本文提出了360DVD，一种基于预训练T2V扩散模型的可控360°全景视频生成方法，通过轻量级360-Adapter插件和360增强技术，解决了现有标准视频生成模型在全景域的内容分布、运动模式和首尾连续性问题，并构建了首个带详细标注的全景视频数据集WEB360。

## 研究问题与动机
1. **全景视频制作成本高**：360°×180°超广视角视频需多鱼眼相机阵列拍摄，耗时耗力，急需文本驱动的生成方案。
2. **现有T2V方法直接迁移效果差**：全景ERP图像与标准视频存在三大差异——(1) FoV更大（360°×180°），(2) 运动多沿曲线而非直线，(3) 首尾需经线连续。
3. **缺乏带标注的全景视频数据集**：现有360°数据集规模小、无文本标注，且ERP格式的极区畸变导致BLIP等工具直接标注质量差。
4. ** panorama video generation 研究空白**：截至本文，尚无工作将扩散模型应用于全景视频生成。

## 核心贡献（创新点）
1. **360-Adapter可插拔适配模块**：通过接收光流等运动条件生成多层级特征注入冻结U-Net编码器，以极小参数将标准T2V模型转换为全景视频生成器，区别于现有LoRA等方法需针对特定模型微调。
2. **360 Enhancement Techniques三合一增强**：提出纬度感知损失（权重矩阵W以cos函数强调低纬度区域）、潜在旋转机制（推理时每步水平旋转潜变量增强首尾宏观连续）、循环填充机制（后T/2步替换卷积填充策略保证像素级连续），三者分别解决内容分布、宏观连续性和微观连续性三个问题。
3. **WEB360数据集构建**：收集约2000个720p ERP格式视频，并结合360 Text Fusion（将ERP投影至4张90°FoV无畸变视图由BLIP标注后由ChatGPT融合）显著提升标注粒度。
4. **首个面向全景视频的扩散模型**：相比仅针对全景图像的PanoDiff、StitchDiffusion等，本文首次将扩散模型延伸至视频领域，支持文本+可选运动条件的可控生成。

## 方法详解
**整体框架**：基于AnimateDiff架构，冻结预训练的SD v1.5和Motion Module v14权重，仅训练360-Adapter。

**360-Adapter设计**：
- 输入：运动条件c（如PanoFlow提取的光流，5D张量 batch×channels×frames×H×W）
- 像素洗牌（pixel unshuffle）降采样至 H/8×W/8
- 4个360-Adapter Block，前3个含下采样模块，每个Block内含2D卷积层和含伪3D卷积的残差块（RB）
- 伪3D卷积：先1×3×3提取空间特征，再3×1×1建模时序信息
- 输出多尺度特征 f_360 = {f_360^1, f_360^2, f_360^3, f_360^4}，逐尺度加到U-Net编码器中间特征：f̂_enc^i = f_enc^i + f_360^i
- 训练时以概率P=0.2将输入置零，避免模型过度依赖运动条件

**损失函数**：
- 基本噪声预测损失：L = E[||ε - ε_θ(z_t^{1:N}, t, τ_θ(y), f_360)||₂²]
- 纬度感知损失：L = E[||W ⊙ (ε - ε̂_θ)||₂²]，其中 W_{i,j} = cos((2i - H/8 + 1)/(H/4) · π)，使低纬度（图像中部）像素获得更高权重

**360 Enhancement Techniques**：
- 潜在旋转机制：推理时每步对 z_t^{1:N} 和 c 执行角度θ的水平循环移位；训练时随机角度旋转作数据增强
- 循环填充机制：仅在最后⌊T/2⌋步使用循环填充替代零填充，兼顾早期布局建模和后期细节完善

## 实验与结果
- **数据集**：WEB360，约2000个ERP视频-文本对，分辨率512×1024，帧数16
- **基线**：AnimateDiff、AnimateDiff+LoRA（LatentLabs360）、AnimateDiff+360ET（仅增强技术）
- **用户偏好研究（31人）**：本文方法在五项指标全面领先——Graphics Quality 51.6%、Frame Consistency 64.5%、End Continuity 71.8%、Content Distribution 67.0%、Motion Pattern 74.6%
- **定性结果**：能够生成符合全景内容分布、运动模式合理且首尾连续的高质量视频；支持多种个性化T2I模型（Realistic Vision、Lyriel、ToonYou、RCNZ Cartoon）的风格迁移
- **消融实验**：移除360TF导致标注质量下降无法生成目标物体；移除伪3D层导致时序闪烁；移除纬度感知损失导致清晰度与视场略降

## 相关工作脉络
1. **标准T2V扩散模型**（AnimateDiff、Make-A-Video、VideoFactory）：继承预训练T2I空间权重并添加时序模块，但未考虑全景特有的FoV和连续性约束，本文将其适配至全景域。
2. **全景图像生成**（PanoDiff、StitchDiffusion、IPO-LDM、DiffCollage）：解决单帧全景合成，本文首次扩展至视频生成，解决时序一致性问题。
3. **GAN-based全景生成**（OmniDreamer、ImmenseGAN）：依赖循环推理或大量私有数据，泛化性受限；本文基于扩散模型，文本可控且无需额外循环推理。
4. **可控视频生成**（MCDiff、LaMD、Video-Composer）：引入多样条件但需大量训练且缺乏即插即用特性；本文360-Adapter轻量、可插拔，兼容多种已有T2I模型。
5. **全景视频超分**（OPDN、参考文献[4] Ntire 2023 Challenge）：面向重建任务而非生成，本文填补生成空白。

## 局限性与未来方向
1. 生成分辨率受限于SD v1.5的512×1024，需额外超分模块才能达到拍摄级分辨率。
2. WEB360仅约2000个视频，数据集规模相对有限，可能制约复杂场景的泛化能力。
3. 仅使用光流作为运动条件，对于更复杂的相机轨迹控制（如3D路径规划）未做探讨。
4. 纬度感知损失虽强调了低纬度区域，但未显式建模极区畸变的几何特性。
5. 未来可结合更高容量基础模型（如SDXL）并扩充数据集以提升生成质量与多样性。

## 研究启发与可借鉴点
1. **轻量适配器迁移范式**：360-Adapter以极小参数将通用T2V模型适配到新域的思路，可迁移至其他特殊视频格式（如鱼眼视频、VR视频、医学视频）的生成任务。
2. **纬度/几何感知损失设计**：cos权重矩阵的思路可用于任何存在空间畸变或非均匀分布的视频/图像生成任务（如极地遥感视频生成）。
3. **循环填充+潜在旋转解决周期性边界**：这一组合策略适用于任何需要首尾/边缘连续性的生成任务，如环幕视频、球面纹理生成。
4. **多视图融合标注策略**：360 Text Fusion将单一高畸变视图分解为多个低畸变子视图再进行语言模型融合，可为其他非欧几里得空间数据（如球面雷达图、拓扑地图）的自动标注提供范式。
5. **训练时随机置零条件的策略**：以概率P=0.2将运动条件置零以增强无条件生成能力，这一技巧可直接复用于其他条件扩散模型。

## 关键术语表
**ERP（Equirectangular Projection）**：等距柱状投影，将360°球面展开为宽高比1:2的矩形图像的标准全景表示格式。
**360-Adapter**：轻量级可插拔模块，接收运动条件生成多尺度特征并注入冻结U-Net编码器，实现T2V模型到全景视频生成的适配。
**伪3D卷积（Pseudo-3D Convolution）**：将3D卷积分解为空间（1×3×3）和时间（3×1×1）两阶段的分离卷积，降低计算开销。
**纬度感知损失（Latitude-aware Loss）**：通过cos权重矩阵W在损失函数中对低纬度（中部）像素赋予更高权重，缓解ERP投影在极区的畸变影响。
**潜在旋转机制（Latent Rotation Mechanism）**：在去噪每一步对潜变量进行水平循环移位，增强生成视频首尾的宏观语义连续性。
**循环填充机制（Circular Padding Mechanism）**：在去噪后半程将卷积层的边界填充从零填充替换为循环填充，保证像素级首尾连续。
**DDIM**：Denoising Diffusion Implicit Models，确定性采样加速方法，本文使用25步完成去噪。
**PanoFlow**：针对全景视频的光流估计网络，用于提取运动条件。

## 可复现要素
- **数据集**：WEB360已公开（项目页面提供下载链接），包含约2000个ERP格式全景视频及360 Text Fusion生成的详细文本标注
- **代码**：项目主页 https://akaneqwq.github.io/360DVD/ 提供代码和模型权重下载
- **关键超参**：分辨率512×1024，帧数16，batch size=1，学习率1×10⁻⁵，训练步数100k，条件置零概率P=0.2；线性beta调度β_start=0.00085，β_end=0.012；推理时DDIM 25步，text guidance scale=7.5，旋转角度θ=π/2
- **基础模型**：Stable Diffusion v1.5 + Motion Module v14
- **运动条件来源**：PanoFlow全景光流估计器
