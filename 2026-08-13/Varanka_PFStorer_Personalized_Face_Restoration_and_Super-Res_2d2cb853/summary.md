# 论文速读：PFStorer: Personalized Face Restoration and Super-Resolution

## 一句话总结
本文提出 PFStorer，一种基于扩散模型的个人化人脸恢复与超分辨率方法，通过少量高质量参考图像学习身份神经表征，在严重退化场景下仍能忠实恢复人物身份并生成细粒度细节。

## 研究问题与动机
- **病态恢复问题的身份保真困境**：人脸恢复是高度病态的，相同低质量输入对应多个可能输出；人类对面部细微差异（眼、鼻、唇形状/颜色）极其敏感，微小变化即可改变身份感知，现有生成式先验方法（如 GAN、CodeFormer）常输出逼真但身份失真的结果。
- **参考图像难以直接迁移**：现有基于参考的方法（DMDNet、ASFFNet）依赖参考图像与低质量输入的几何/外观对齐，实际场景中姿态、光照、语义差异导致身份转移困难。
- **退化程度与身份丢失的矛盾**：轻度退化时模型可保留身份，重度退化时基础模型往往输出完全不同身份（图 2d），缺乏个人先验无法实现忠实恢复。
- **训练捷径问题**：多数训练样本退化较轻，低质量图像本身包含足够身份信息，模型易产生"捷径"，忽略参考图像，导致极端场景下个性化失效。

## 核心贡献（创新点）
1. **基于适配器的个人化保留框架**：冻结预训练基础模型，仅在 UNet 各层插入可训练 Personalization Block（含文本嵌入与参考图像特征的交叉注意力），避免破坏基础模型的丰富生成先验。
2. **生成正则化器（Generative Regularizer）**：通过随机丢弃 LQ 输入、强制模型仅凭参考图像生成身份，促使学习更鲁棒的神经身份表征，解决训练捷径问题。
3. **逐层可控个性化向量 γⁱ**：为每个 Personalization Block 引入可学习向量 γⁱ 控制个性化注入强度，平衡基础恢复输出与身份个性化细节。
4. **无标记对齐的自由训练策略**：采用随机裁剪替代传统 landmarks 对齐，提升模型对姿态变化的鲁棒性，同时支持高分辨率 patch 输入与 tiling 超分辨率。

## 方法详解
**整体架构**（图 3）：以 StableSR [35] 初始化为基础模型，在 UNet 每层包含两部分：
- **Base Model Block**：保持 Stable Diffusion 原有结构，叠加 Spatial Feature Transformation (SFT) 块接收 LQ 条件特征。
- **Personalization Block**：在 Base Block 输出后，对中间特征 Fⁱ 进行文本嵌入 learnable text embedding [10]、参考图像特征 F_Refⁱ 与 Fⁱ 之间的双向交叉注意力。参考图像特征由冻结的 Stable Diffusion 提取（同一批次通过 Base Model 前向传播获得）。

**可控适应公式**（公式 3）：
```
F̂ⁱ = Fⁱ + γⁱ ⊙ Personalization-Block(Fⁱ, F_Refⁱ)
```
γⁱ 初始化为 0，逐层学习平衡基础恢复与个性化注入的比例。

**扩散损失**（公式 2）：
```
L_Diff = E_{z,t,I_LQ,I_Ref,ε} ||ε - ε_θ(z_t, c, I_LQ, I_Ref)||₂
```
ε_θ 为条件扩散模型，c 为文本条件，I_LQ 为低质量输入，I_Ref 为参考图像。

**生成正则化损失**（公式 4）：
```
L_Gen = E_{z,t,I_LQ,I_Ref,ε} ||ε - ε_θ(z_t, c, ∅, I_Ref)||₂
```
将 LQ 输入替换为空值 ∅，强制模型无条件生成身份。

**总损失**（公式 5）：
```
L = L_Diff + λ_Gen·L_Gen + λ_Pers·L_Pers
```
L_Pers 为正文本嵌入 token 的交叉注意力正则化项 [14]，λ_Gen 默认设为 0.1。

**训练流程**：
1. Base Model 训练：以 StableSR 初始化，在 FFHQ 上使用随机裁剪 + 二阶噪声模型（ISP [41]、运动模糊、中值模糊）微调。
2. 个人化微调：对每个目标身份，用 3-5 张参考图像进行 500 次迭代微调（单卡 A100 约 10 分钟）。

## 实验与结果
**数据集**：Celeb-Ref [24] 子集（20 身份，每身份至少 10 张，共 342 张）；242 张用于测试（每身份预留 5 张作为参考）；另含真实世界图像（从 LAION-5B-KNN 反向搜索获取）。

**评估指标**：PSNR、SSIM、LPIPS、MUSIQ、LMSE（Landmark MSE）、ID（ArcFace 余弦相似度）。

**基线方法**：CodeFormer [45]、DR2+SPAR [38]、DMDNet [24]（使用相同 5 张参考图像）。

**重度退化定量结果**（表 1）：
| 方法 | PSNR↑ | SSIM↑ | LPIPS↓ | MUSIQ↑ | LMSE↓ | ID↑ |
|------|-------|-------|--------|--------|-------|-----|
| CodeFormer | 22.26 | 0.642 | 0.422 | 60.92 | 33.34 | 38.33 |
| PFStorer (Ours) | 22.62 | 0.679 | 0.414 | 64.04 | 18.37 | **57.18** |

PFStorer 的 ID 指标达 **57.18%**，较第二名 CodeFormer（38.33%）**提升近 20 个百分点**；LMSE 降低约一半。

**用户研究**（图 8）：40 名用户，100 张测试图像，共 8000 份回答。PFStorer 在"质量+身份忠实度"综合评选中获 **61%** 首选票，第二名 CodeFormer 仅 25%，差距达 **36.6 个百分点**。

**消融验证**（表 2）：Base Model 已优于 StableSR；添加 DreamBooth [30] 或 ViCo [14] 全参数微调反而降低 PSNR 并增加 LMSE，证明冻结基础模型 + 适配器的有效性；加入 γ 后 PFStorer 全面领先。

## 相关工作脉络
1. **CodeFormer [45]**：基于离散码本与 adversarial training 的 SOTA 恢复方法，存储高质量人脸数据；本文在其基础引入个人化，解决其身份失真问题。
2. **DMDNet [24]**：构建深度特征字典并通过对齐模块融合参考图像；本文与之对比，但无需严格对齐，学习的是神经身份表征而非像素级特征匹配。
3. **DreamBooth [30]**：首个 few-shot 文本到图像个人化方法，通过覆写罕见文本嵌入实现；本文将其思想迁移至恢复任务，但采用适配器而非全量微调。
4. **ViCo [14]**：在 UNet 交叉注意力层添加图像适配器；本文与其对比（表 2），证明 ViCo 全参数微调会破坏基础先验，而 PFStorer 的逐层 γ 控制更有效。
5. **StableSR [35]**：通用图像超分扩散模型；本文以其为 Base Model 初始化，通过人脸数据集微调增强恢复能力。
6. **DiffBFR [28]**（同期工作）：使用级联扩散模型分离身份与纹理恢复；本文走个性化路线，鼓励忠实重建而非多样性。

## 局限性与未来方向
- **参考图像外观一致性要求**：若参考图像与输入图像存在显著外观变化（如图 10），输出可能不符合预期；模型忠实于参考图像而非输入本身。
- **扩散模型采样速度慢**：继承 Stable Diffusion 的随机性导致的伪影与幻觉问题，推理速度受限。
- **极端退化时的语义错误**：当输入信息极低时（图 2d），个性化细节可保留，但语义结构可能不正确。
- **未来方向**：结合 Emu [6] 等视觉引导方法缓解随机性；探索更高效的采样策略以加速推理。

## 研究启发与可借鉴点
1. **冻结基础模型 + 适配器个人化**：该策略可迁移至其他生成任务（如图像编辑、风格迁移），避免灾难性遗忘的同时实现高效微调。
2. **生成正则化器的设计思想**：在条件生成任务中引入无条件的"纯生成"辅助损失，防止模型依赖输入条件中的捷径信息，适用于更多条件生成场景。
3. **无标记对齐训练**：随机裁剪替代 landmarks 对齐不仅提升鲁棒性，还天然支持超分辨率与 tiling，值得在人脸/生物医学图像任务中推广。
4. **逐层可控注入向量 γⁱ**：为不同分辨率层分配独立控制参数，实现细粒度个性化-恢复平衡，可用于多尺度生成网络设计。
5. **从恢复模型到个人化恢复模型**：与"个人化生成模型 + 附加任务"（MyStyle、IdentityEncoder）的思路相反，本文直接从恢复模型出发添加个人化模块，保留原有恢复先验，设计更简洁高效。

## 关键术语表
**PFStorer**：Personalized Face Restorer 的缩写，本文提出的个人化人脸恢复与超分辨率框架。
**Personalization Block**：插入在基础模型每层后的适配器模块，通过交叉注意力融合参考图像特征与中间特征。
**Generative Regularizer**：在训练时随机丢弃 LQ 输入，强制模型仅凭参考图像生成身份的辅助损失。
**ArcFace ID**：使用 ArcFace [7] 提取的特征向量计算余弦相似度，用于量化恢复结果的身份保真度。
**LMSE**：Landmark Mean Squared Error，测量预测人脸关键点与 GT 关键点的均方误差。
**StableSR**：基于 Stable Diffusion 的通用图像超分辨率模型，本文作为 Base Model 初始化来源。
**SFT (Spatial Feature Transformation)**：空间特征变换模块，将低质量图像特征注入扩散模型中间层。
**Tiling**：将大图像分割为重叠 patch 分别超分辨率后拼接，支持超过 512×512 的超分辨率输出。
